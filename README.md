# Orbit Shift

Orbit Shift is an interactive Flexbox learning game built with semantic HTML, CSS, and vanilla JavaScript.

## Play

- Live game: https://eldarush.github.io/flexbox-orbit-game/
- Repository: https://github.com/eldarush/flexbox-orbit-game

## Local preview

Open `index.html` in a modern browser. No installation or build step is required.

## What the game teaches

Eight missions combine these Flexbox properties:

- `display: flex`
- `flex-direction`
- `justify-content`
- `align-items`
- `flex-wrap`

Players can change the properties, check a solution, reset a mission, revisit completed missions, and keep progress in the browser.

The game uses no external JavaScript libraries and does not use CSS Grid for any mission or layout solution. The 640 × 360 mission board keeps the same dimensions at every screen size and is placed in a horizontal scroll area on narrow screens.

## Submission checklist

- Eight distinct missions, including two wrapping formations
- Clear instructions and visible target beacons for every mission
- Correct and incorrect feedback with controlled next-mission progression
- Current mission indicator, reset control, attempts, score, and saved progress
- Responsive interface with a fixed-size mission board
- Public GitHub repository, GitHub Pages link, and standalone ZIP archive

## Project files

- `index.html` - semantic game interface
- `styles.css` - responsive design and Flexbox layouts
- `script.js` - mission data, controls, validation, scoring, and saved progress
