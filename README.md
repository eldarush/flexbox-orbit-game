# Orbit Shift

A dark-themed, responsive Flexbox practice game built with semantic HTML, CSS, and vanilla JavaScript.

- Live game: https://eldarush.github.io/flexbox-orbit-game/
- Repository: https://github.com/eldarush/flexbox-orbit-game

The project contains 12 missions with mission-specific Flexbox controls, position-based answer checking, hints, attempts, timers, scores, ratings, saved progress, replay, and a separate statistics page. The game board remains 640 × 360 at every screen size and scales visually on smaller displays.

No external JavaScript libraries or CSS Grid are used. Open `index.html` in a browser to play locally.
